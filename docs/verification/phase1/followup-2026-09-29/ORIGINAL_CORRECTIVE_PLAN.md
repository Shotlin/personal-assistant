# Remaining Phase 1 corrective plan

This plan is for a subsequent owner-started implementation run. It does not authorize execution during this review. Preserve the existing Deep Agent, structured JEV + CUA path, bounded Velo recipes/fast path, Sani/Tauri architecture, working local STT, selected API providers and all safety controls. Do not replace them with a new agent framework. Keep experiment/promotion/RSI execution disabled. No Phase 2 or Phase 3 implementation or deep planning.

The original architecture remains: one durable MissionService over the existing Deep in PLAN/RECOVER/REVIEW roles; deterministic mission state/authority/verification; bounded Velo execution with JEV selection and CUA; SQLite ledger and payload/evidence boundaries; actual host owner controls and separate local voice worker; read-only Observer.

## Exit criteria

All D findings must have source-backed closure and a positive plus a meaningful negative test. Prior working behaviors must remain intact. No duplicate synthetic effect, wrong-target sink call, raw canary persistence/egress, post-stop dispatch, forged approval or unsupported completion is acceptable. A detected violation is a hard failure requiring a fix and affected regression rerun. Do not describe all Phase 1 as complete while a required harness or product workflow is missing. If offline code is ready but authorized live evidence is unavailable, the honest result is IMPLEMENTED/FIXTURE-VERIFIED where justified and PHASE 1 NOT YET ACCEPTED overall.
